# 社会学与人口学期刊文献数据库使用指南

本指南面向社会学、人口学及相关领域的学生和研究者，不要求编程基础。

当前发布快照收录 **31 本期刊、56,019 条文章元数据**，年份覆盖 **1947–2026**。其中 **55,946 条记录有 DOI**，并提供对应的单篇 JSON 端点。数据库会继续更新，最新统计以 [Pages API 概况](https://huwenbo-lab.github.io/publication/api/overview.json) 为准。

在线使用：[https://huwenbo-lab.github.io/publication/](https://huwenbo-lab.github.io/publication/)

## 这个数据库适合做什么

它适合：

- 在收录的 31 本期刊中按标题、摘要、作者、期刊和年份查找候选文献；
- 快速了解某个主题在特定期刊和年份范围内有哪些相关记录；
- 整理待读清单、收藏文件夹，并导出 BibTeX、CSV 或 JSON；
- 为 AI 工具提供分批、结构化的文献元数据。

它不等于：

- 论文全文库：这里没有 PDF，也没有论文正文；
- 覆盖整个学科的系统综述数据库：期刊范围是预先选定的 31 本期刊；
- 可直接引用的最终书目信息源：当前主数据没有卷、期、页码等字段；
- 对论文理论、方法和结论的完整说明：摘要只能支持初步筛选。

部分早期记录没有摘要，少量记录也可能缺作者或 DOI。遇到关键信息缺失时，应通过期刊官网、DOI 页面、图书馆或其他可靠来源核对。

## 一、直接使用在线网页

打开在线数据库后，页面会优先加载浏览器内的 SQLite 检索库；如果该文件不可用，会回退到 `data.json` 进行基础检索。

### 1. 选择期刊

页面顶部横向排列期刊按钮：

- 点击某本期刊可加入筛选；
- 可以同时选择多本期刊；
- 再次点击可取消；
- 点击 `All` 可清除期刊筛选。

### 2. 输入关键词并选择搜索范围

搜索框右侧有四种模式：

- **全部字段**：同时搜索标题、摘要、作者、期刊和年份；
- **标题与摘要**：适合查研究主题；
- **作者**：适合按作者姓名查找；
- **期刊**：适合按期刊名查找。

示例关键词：

```text
education inequality
"social mobility"
marriage OR cohabitation
fertility NOT mortality
```

精确短语可加英文双引号。多个普通关键词默认要求同时匹配；`OR` 用于扩大范围，`NOT` 用于排除。

### 3. 进一步筛选和排序

点击 `Filters` 后可以：

- 设置起始年份和结束年份；
- 只看有摘要的记录；
- 查看并移除已经选择的期刊。

`Sort` 菜单支持：

- 年份新到旧；
- 年份旧到新；
- 按标题；
- 按作者；
- 按期刊。

结果较多时，页面底部的 `Load more` 会继续加载下一批。

### 4. 查看一条记录

点击文章标题可展开详情。根据该条记录是否有相应字段，详情区会提供：

- 摘要；
- DOI 链接；
- Google Scholar 搜索；
- 加入收藏文件夹；
- 复制 BibTeX；
- 复制 APA 格式草稿；
- 复制供 AI 使用的提示词。

BibTeX 和 APA 内容只由现有元数据生成。由于数据库目前没有卷、期和页码，正式写作前必须回到 DOI 页面或论文全文核对并补全。

### 5. 按作者查看

点击页面右上角的 `Authors`：

- 输入最低发文数，筛选在本数据库中达到该数量的作者；
- 作者列表按数据库内发文数排序；
- 点击作者后会返回主检索页，并自动按作者名搜索。

作者统计采用保守的姓名规范化。缩写、同名、改姓和不同出版平台的姓名格式都可能导致拆分或误合并，因此不能把这里的数量当作作者完整发表记录。

## 二、使用收藏

点击右上角星形按钮进入收藏页。收藏默认保存在当前浏览器的 `localStorage` 中：

- 不需要注册账号；
- 默认不会上传到服务器；
- 清除浏览器站点数据、切换浏览器或设备后可能丢失。

收藏页支持：

- 新建多级文件夹，例如 `婚姻与家庭/婚配`；
- 重命名文件夹；
- 删除空文件夹；
- 通过下拉菜单或拖动把文章移动到其他文件夹；
- 按当前文件夹导出 BibTeX、CSV 或 JSON。

当前网页只提供导出，不提供从文件导入。建议定期导出 JSON 作为本地备份。

### 可选同步是高级功能

收藏页还提供 `Sync endpoint` 和 `Sync key`。这不是数据库默认服务，而是给已经自行部署兼容同步端点的用户使用：

- 只有用户主动填写、保存并点击 `Pull` 或 `Push` 时才会联网同步；
- 收藏数据会发送到用户填写的端点；
- endpoint 和 key 保存在当前浏览器本地；
- 不清楚端点来源或安全性时，请不要配置。

普通用户只使用本地收藏和导出即可。

## 三、在本地进行元数据检索

本地检索使用 Python 标准库和 SQLite FTS5，对标题、摘要、作者、期刊和年份建立索引。它检索的是元数据，不是论文正文。

### 1. 获取项目并进入目录

```bash
git clone https://github.com/huwenbo-lab/publication.git
cd publication
```

确认已安装 Python 3：

```bash
python3 --version
```

Windows 用户可将下面命令中的 `python3` 替换为 `python` 或 `py`。

### 2. 构建本地索引

```bash
python3 scripts/build_search_db.py
```

命令会在项目根目录生成 `literature.db`。该文件是可重建的本地产物，不需要提交到 Git。

### 3. 搜索

```bash
# 基本搜索
python3 scripts/build_search_db.py --search "education inequality"

# 限制返回数量
python3 scripts/build_search_db.py --search "marriage fertility" --limit 10

# 限定期刊
python3 scripts/build_search_db.py \
  --search "stratification" \
  --journal "American Journal of Sociology"

# 限定年份
python3 scripts/build_search_db.py \
  --search "labor market" \
  --year-from 2015 \
  --year-to 2023
```

`articles.json` 更新后，可强制重建：

```bash
python3 scripts/build_search_db.py --rebuild
```

项目维护、数据更新和全量重建见[维护与自动更新流程](../workflows/maintenance_workflows.md)。

## 四、让 AI 分批读取数据库

不要把整个 `articles.json` 一次性放进 AI 上下文。推荐按“数据库概况 → 标题初筛 → 摘要复筛 → 全文核对”的顺序缩小范围。

### 1. 先看数据库和期刊索引

```text
https://huwenbo-lab.github.io/publication/api/overview.json
https://huwenbo-lab.github.io/publication/api/journals.json
```

`api/journals.json` 同时提供每本期刊的文件名 `slug`。多词期刊名在文件路径中使用下划线，例如：

```text
American_Sociological_Review
Journal_of_Marriage_and_Family
Gender_and_Society
```

不要把带空格的期刊显示名称直接代入文件 URL。

### 2. 用标题文件初筛

```text
https://raw.githubusercontent.com/huwenbo-lab/publication/main/lit_db/titles/by_journal/Demography.md
https://raw.githubusercontent.com/huwenbo-lab/publication/main/lit_db/titles/by_journal/Journal_of_Marriage_and_Family.md
```

标题只能用于判断“可能相关”，不能据此判断论文的具体方法和结论。

### 3. 再读相应年份段的摘要

```text
https://raw.githubusercontent.com/huwenbo-lab/publication/main/lit_db/abstracts/2020_present/Demography.md
https://raw.githubusercontent.com/huwenbo-lab/publication/main/lit_db/abstracts/2010_2019/Demography.md
https://raw.githubusercontent.com/huwenbo-lab/publication/main/lit_db/abstracts/2000_2009/Demography.md
```

网页中的 `AI prompt` 按钮也会生成单篇 JSON、本刊标题索引、相应年份段摘要索引和数据库概况链接。

### 4. 一个更稳妥的 AI 提示词

```text
以下材料来自一个期刊元数据库，只包含标题、摘要、作者、期刊、年份和 DOI，
不包含论文全文。请先按研究问题把记录分成：
1. 可能需要直接对话的文献；
2. 理论或概念来源；
3. 经验或方法先例；
4. 竞争解释；
5. 仅凭摘要无法判断。

每篇说明“为什么值得进一步读”，不要把摘要推断写成论文已经证实的结论，
也不要直接生成可用于正式论文的引文。最后给出需要获取全文的优先阅读清单。
```

## 五、从候选文献走到正式论证

建议把数据库用于“发现和初筛”，而不是代替阅读：

1. 用标题和关键词形成宽松候选集；
2. 阅读摘要，记录每篇与研究问题的可能关系；
3. 对准备进入正文的文献获取并阅读全文；
4. 核对理论主张、样本、变量、方法、结果、局限和具体页码；
5. 从正式来源补全卷、期、页码等书目信息；
6. 写作时只引用已经读过、且确实支持相应论断的文献。

仅凭数据库没有检索到某篇文章，不能证明相关研究不存在；若要提出“文献空白”或覆盖性主张，还需要扩展到数据库之外的检索渠道。

## 常见问题

### 搜索结果为空

减少关键词数量，改用同义词，或扩大期刊和年份范围。主题词通常使用英文效果更好。

### 某条记录没有摘要

这通常是来源元数据未提供摘要。可用 DOI 或标题到期刊官网、Google Scholar 或图书馆查找全文。

### 没有 DOI

没有 DOI 的记录不会生成单篇 DOI JSON 端点，但仍可通过网页、`articles.json` 和本地 SQLite 索引检索。

### 收藏不见了

收藏默认只保存在浏览器本地。检查是否换了浏览器、设备或浏览器配置；以后可定期导出 JSON 备份。

### 引用信息不完整

当前数据库没有卷、期和页码字段。网页生成的 BibTeX/APA 只是草稿，请以论文正式页面或全文为准。
